MAYMAY OFFLINE INSTALLER
========================

1. Keep every installer file together in the same folder.
2. Optional but easiest: place the MayMay Firebase Admin JSON in the host
   computer's Downloads folder before running the installer. If using the
   extracted installer folder, it can also be placed beside the installer.
   The filename begins with:
   maymaydata-a6fda-firebase-adminsdk-
3. Double-click Install-MayMay.cmd.
4. Start MayMay from the desktop shortcut.
5. Allow Node.js through Windows Firewall on Private networks only.
6. Caregivers on the same network can open http://maymay.local/

The installation itself requires no internet connection. MayMay requires an
internet connection while running for Firebase sign-in and synchronization.

SECURITY
--------
The Firebase Admin JSON is not included in this installer. Transfer it only to
the host computer, preferably by USB, and never give it to a caregiver.
